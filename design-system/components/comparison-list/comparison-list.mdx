# Side-by-Side Comparison List

A split 3-column project comparison layout extracted from the dark-theme Projects view (`main/index3.html`).

## Anatomy

1. **Left Column (40% width / 5 cols)**: Right-aligned project title set in bold narrow display font (`font-narrow-semibold`), reaching towards the center.
2. **Center Column (20% width / 2 cols)**: Centered technical vector icon. When active or hovered, reveals a 4-corner pixel bracket frame created with CSS `conic-gradient` that scales in smoothly (`scale: 1.25` → `scale: 1`).
3. **Right Column (40% width / 5 cols)**: Left-aligned detailed architectural narrative set in high-contrast body typography.
4. **Interactive States**: Inactive rows are dimmed to `0.38` opacity. Hovering or clicking any row activates it to `1.0` full brightness.
