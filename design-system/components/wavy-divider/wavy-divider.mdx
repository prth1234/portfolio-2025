# Wavy Section Divider

A seamless, full-width fluid SVG wave connecting the pitch black `.plan` section to the warm cream `.service` section on the main portfolio page. Traced with a vibrant yellow wave boundary stroke (`#ffe32e`, width 4.5px).

## Live Preview

<Canvas of={WavyDividerStories.Default} />

## Anatomy
- **Container**: Zero-line-height wrapper with negative margins to prevent subpixel antialiasing gaps between sections.
- **Top Fill Path**: Perfectly closes into the top section.
- **Bottom Fill Path**: Perfectly closes into the bottom section.
- **Stroke Path**: 4.5px curved yellow boundary path across 1440 coordinate units with cubic bezier wave segments.
