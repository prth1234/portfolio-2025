# Button

The primary interactive action element used throughout the portfolio, notably for the contact form submission (`ENTER` button) and section calls to action. Styled as a high-visibility pill in the signature yellow `#ffe32e` with an animated directional arrow.

## Anatomy
- **Label**: Monospace uppercase text with `0.08em` tracking.
- **Icon**: Right-aligned arrow that hops on hover with bouncy spring easing.
- **Pill Container**: Rounded `9999px` corners, subtle shadow border.

## Accessibility (A11y)
- Uses native `<button>` element with keyboard focus-visible indicator.
- Interactive states (hover, active, focus, disabled) are fully supported with accessible outline rings and disabled contrast handling.
