## Component Architecture

- `tokens/`: CSS custom properties (`tokens.css`) & machine-readable W3C token definitions (`tokens.json`).
- `styles/`: Base CSS reset, typography scale utilities, light/dark themes, and icons.
- `components/`: 16 production-grade UI components with exact CSS, isolated stories, and autodocs.
- `foundations/`: Interactive token catalogs for Colors, Typography, Spacing, Motion, and Iconography.
- `dist/`: Unified standalone distribution file `dist/design-system.css` (50 KB).
