# Squiggle UI Design System

> **A reverse-engineered, production-grade design system extracted with 1:1 fidelity from portfolio-2025.**

Squiggle UI encapsulates the distinctive editorial and retro aesthetic of the portfolio:
- **Hand-drawn Yellow Underline**: SVG data URI wave pattern that accents titles and expands on accordion interactions.
- **High-Contrast Palette**: Warm cream canvas (`#f9f4eb`), pitch dark surfaces (`#000000`), and signature yellow accents (`#ffe32e`).
- **Editorial Typography**: Condensed narrow headers, monospace metadata labels, and clean body text.
- **Pixel-Art Elements**: Micro-radii, spinning windmills, and signal status indicators.

---

## Architecture

- `tokens/`: CSS custom properties (`tokens.css`) & JSON specification (`tokens.json`).
- `styles/`: Base resets, typography scales, light/dark themes, and icons.
- `components/`: Modular component styling, templates, and interactive stories.
- `foundations/`: Swatches, type specimens, spacing visualizers, and easing curves.
- `dist/`: Unified bundle `dist/design-system.css` for zero-configuration inclusion in any project.
